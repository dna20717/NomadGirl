Übersicht: `python3 .claude/skills/nomadpixel/scripts/analyse.py bibliothek .claude/nomadpixel-bibliothek`

|---|---|---|

Neue Bausteine: nach einem Auftrag, der gut ankam, die gelungenen Teile als `[part name]` in eine passende Datei (z. B. `waffen.pix`, `glas.pix`) und hier eintragen.
