# Glitchlings

Passive Companions: spezialisierte KIs mit Macken, die es statt Software gibt (design.md › Hacking v3: Glitchlings). Stufe 1 (#047): der Generator.

- **Auftrag** (Daniel, 16.11.2026: „Das Konzept von Software existiert in dieser Welt nicht mehr … spezialisierte KIs, die alle kleine Eigenarten und Macken haben … mit einem starken Deck fangen oder überreden … in Werkbänke einziehen … permanent Cyberware verbessern … einzigartig“; 17.11.2026: „Namen nach dem Schema wie Marble Sting … das hebt sie von Pokémons ab (obwohl sie im Kern genau das ja sein werden) … ein System, auf dessen Basis man diese passiven Companions generieren kann“).
- **Werkstatt** › GLITCHLINGS › Glitchlings (`data/glitchlings.json`, einzeln): **Generator** (je Durchgang 12, Gewicht je Stärke 1–5 Bits 40/30/18/9/3, Fremde Werkbank 35 %), **Namen** (erstes Wort Material/Farbe, zweites Wort Kante/Geräusch/Tat; Name = zwei Wörter, jedes Wort je Durchgang nur einmal), **Begabungen** (Name, Werkbank + Auch als Werkstatt-Funktion, Effekt mit `{n}` = je Bit × Bits, Schlüssel `stat` fürs Spiel: perfect, refund, growth, power, strain, fuel, weaponDamage, battery, rest, value, freshness, sleepHeal), **Macken** (Text + Art: schrullig, Laune, Tageszeit, Wetter, Nachbarn), **Wünsche**, **Wohnorte** (Maschinen in POIs), **Unikate** (handgemacht, „immer“ = in jedem Durchgang: **Amber Slay** (Daniel), Waffenmeister 4 Bits; **Marble Sting**, Chirurg 5 Bits, weiß etwas über die Kinder in den Tanks). Vorschau „Ein Durchgang“ mit Karten (Name, Bits, Begabung, Wohnort, Effekt, Macke, Wunsch) und „Neu würfeln“.
- **Generator** `game/glitchlings.js` (ohne DOM): `generate(D, seed, count)` → Glitchlings `{ id, name, unique, talent, function, also, bits, effect, stat, value, quirk, quirkKind, wish, home, description }`; Unikate „immer“ zuerst, der Rest gewürfelt (gleicher Seed = gleiche Glitchlings, Macken und Wünsche wiederholen sich nicht, solange genug da sind); `effectOf(C, talent, bits, own)`: in der eigenen Werkbank voll, sonst „Fremde Werkbank“ %. Test `test/glitchlings.test.js`.
- **Noch nicht im Spiel** (kommende Stufen, design.md): Fangen mit dem Deck, Einzug in Werkbänke (die Effekte wirken), Überreden, Verschmelzen mit Implantaten, Kaufen/Erben, Crew-Anbindung, Traum.
