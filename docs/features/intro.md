# Intro

Das Intro als Comic (#005): acht Panels auf vier Seiten, Textboxen, Countdown, Effekte aus Code; nur über das Hauptmenü.

- **Auftrag** (Daniel, 12.11.2026: „lass uns ein Intro für das Spiel malen“, dazu sein Storyboard mit 6 Panels): Inhalt **die Suche** (AvA im Cryo-Tank, Leyla klaut den Tank aus dem Klinikturm in BigCityDelta, flieht in die Wastelands, der Tank läuft auf Notstrom, die Tankstelle KM7 hat die Teile), Form **Comic-Panels**, Start **nur, wenn man es im Hauptmenü aktiv auswählt**, Budget **großes Kino** nach dem Storyboard. Weitere Antworten: das erste Camp als eigenes Panel 4b (Van + Anhänger mit Tank + Feuer, keine NPCs, keine Drohne), Countdown **beides** (Tage wie im Storyboard + Tank-Zustand als Balken wie im Spiel), **Textboxen** ohne KI-Floskeln, Schluss: **AvA erwacht** in der Drohne. Wichtig laut Daniel: Leyla, Tank, Tankstelle, Van und Camp sollen wie im Spiel aussehen.
- **Ablauf:** Seite 1 = Klinikturm, Alarm, Flucht, Notstrom (03 TAGE, Tank 30 %); Seite 2 = Erstes Camp (Kilometer 6) und Tankstelle Kilometer 7 (überlappend); Seite 3 = Null Tage (00 TAGE, Balken blinkt, Wachen, Suchscheinwerfer); Seite 4 = AvA erwacht neben dem Tank am Van („Leyla? Ich bin hier drin.“). Danach Titel „NomadGirl“ (ohne Untertitel) und zurück ins Hauptmenü.
- **Seite** `intro.html` (online `/intro`, `tools/build_web.mjs` kopiert sie mit), Hauptmenü-Eintrag „Intro“ an zweiter Stelle in `index.html`. Player `game/intro/intro.js` (`startIntro(canvas, { onEnd, startAt })`), Canvas ohne Phaser, Seite 1920 × 1080 logisch, skaliert mit Rand.
- **Bereich Intro** (Katalog, `data/intro.json`, Gruppe Grundlagen, nach Seiten gruppiert): je Panel Seite, Reihenfolge, Bild (Asset), Position + Größe in % der Seite, **Kamerafahrt** (heran, weg, Schwenk links/rechts/oben), **Effekt** (Blasen im Tank, Alarm mit rotem Licht + Wackeln, Staub, Funken vom Feuer, Suchscheinwerfer, Erwachen mit Flackern + Cyan-Licht) mit Effekt-Ort, **Textboxen** (Tabelle: Erzähler = gelbe Box, Leyla/AvA = dunkle Sprechbox mit Namensschild, Ecke), **Anzeige** (großer Text, Wort darunter, Balken %, Mitte, Größe, Stil Warnung/Hologramm; dunkles Glas dahinter), automatisch weiter nach x s. Startseite › **Intro**: Schreibtempo, Erscheinen, alte Panels abdunkeln, Kamerafahrt, Titel und Untertitel am Ende.
- **Bedienung:** weiter = Enter, Leertaste, →, Klick, A, RB (erst schreibt die Box fertig, dann kommt die nächste, dann das nächste Panel); zurück = ←, LB; überspringen = Esc, B, Start (erst zum Titel, nochmal = Hauptmenü). Werkstatt › **Spielen** im Bereich Intro öffnet das Intro ab dem gewählten Panel (`intro.html?panel=<id>`).
- **Bilder:** PixelLab Create Image Pro 688 × 384 mit AAP-64, Referenzen: das Storyboard-Panel (Bildaufbau), Leylas Character Sheet, `ws_cryotank_1`, der Van, für das Camp eine Montage aus Van + `trailer_flat` + Tank, für AvA das Drohnen-Konzept. PixelLab lässt bei Referenzbildern einen Rand stehen, der per Code abgeschnitten wird (Originale in `assets/intro/raw/`, Panels ≈ 480 × 268). In Panel 5 wurde die „5“ aus dem Storyboard übermalt. Zahlen und Schrift kommen nie aus der KI, sondern aus Code (Anzeige).
- **AvA wie im Spiel** (Daniel, 13.11.2026: „Du nutzt den falschen Sprite für die Drohne im Spiel. Wichtig ist auch, dass die Szene mit der Drohne und der Tank neben dem Van stehen und nicht in einem riesigen Labor“): Panel 7 zeigt jetzt das Camp bei Nacht nah am Van (Tank auf dem Anhänger, Glut), AvA setzt der Player aus Code hinein (Intro › **AvA**: zeigen, Mitte, Größe, wacht auf nach, Gesicht, gespiegelt) mit Hülle, Gesicht, Glanz und angebauten Teilen aus dem Bereich Drohne: erst dunkel, dann flackert das Gesicht an, Cyan-Leuchten, sie schwebt und blinzelt. Titel am Ende **ohne Untertitel** (Daniel).
- **Fernsteuerung** `window.intro`: `next()`, `back()`, `skip()`, `state()` (Panel, Seite, Textbox, schreibt noch, Ende), `panels`, `images`. Test `tools/intro_test.mjs` (15 Prüfungen).
