# Glossar: Deutsch → Englisch

Ordner, Dateien, Bezeichner, Kommentare und die Feldnamen der Spieldaten sind englisch. Deutsch bleiben Texte in Oberflächen, Namen und Beschreibungen in den Spieldaten, Commit-Nachrichten, `CLAUDE.md` und die Docs. Inhalts-IDs dürfen deutsch bleiben.

Neuer Code nimmt die Wörter aus dieser Liste. Die Grundbegriffe (Werkstatt, Prüfung, Bereich …) folgen dem Glossar von NomadTactics.

| Werkstatt (Raum im Rig) | workshop (Daten: `workshops`) |
